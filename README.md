# 漢字 de クラッシュキーボード

漢字の読みをローマ字で入力しながら、キーの摩耗と破損を管理するタイピング・サバイバルパズルです。

- サーバー、データベース、ビルド作業不要
- `index.html` を開くだけで起動
- GitHub Pagesへそのまま配置可能
- 30秒スコアアタック／20語クリアの2モード
- 初級・中級・上級・超級・鬼の5難易度
- 1,048語、1,058通りの読みを収録
- 各モード・各難易度の上位5記録をブラウザの `localStorage` に保存
- 結果共有と、ハイスコア画像のSNS共有に対応

## すぐ遊ぶ

1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. 物理キーボードでプレイします。

一部ブラウザではローカルファイルからの保存機能が制限される場合があります。公開時はGitHub Pages等の静的ホスティングを推奨します。

## GitHub Pagesへ公開

このZIPの**中身**をリポジトリ直下へ置いてください。

```text
index.html
game.js
styles.css
manifest.webmanifest
assets/
data/
tools/
```

GitHubのリポジトリ画面で以下を設定します。

1. `Settings`
2. `Pages`
3. `Build and deployment` を `Deploy from a branch`
4. Branchを `main`、フォルダを `/(root)`
5. `Save`

## ゲームルール

### 問題

画面に漢字語が3つ表示されます。いずれか1語の読みをローマ字で入力し、Enterを押します。問題カードを選択する操作はありません。

### キーの摩耗

同じ判定で使用したキーは、次の順に悪化します。

1. 正常 → 黄色
2. 黄色 → 赤・ひび割れ
3. 赤 → 破損

正解した1語の間に一度も使わなかったキーは、1段階回復します。

誤答時は、その判定までに使ったキーだけ摩耗し、未使用キーは回復しません。入力した文字をBackspaceで消しても、文字キーを使用した事実は残ります。Backspace自身も摩耗します。Enterは毎回必須のため、摩耗対象外です。

### 破損からの復帰

30秒モード・20語モードのどちらも、破損からゲーム内時間10秒で正常へ復帰します。

20語モードではクリアタイムもスコアへ影響するため、再抽選するか、復活を待って入力するかをプレイヤーが選べます。

### 20語モードのHP

20語モードにはハート5個のHPがあります。誤入力で1個減り、5回目の誤入力でゲームオーバーです。空欄でEnterを押した場合はHPを消費しません。

### 再抽選と入力不能状態

1ゲームにつき1回だけ、表示された3語を再抽選できます。3語すべてが破損キーを含む場合も即ゲームオーバーにはならず、最短復活時間を表示します。復活を待つか再抽選を使うか選択できます。

### 終了時の読み表示

タイムアップまたはHP切れによるゲームオーバー時は、その時点で表示されていた3語について、すべてのひらがな読みとローマ字入力例を結果画面に表示します。

## スコア

正解語の難易度、正解した読みの標準ローマ字数、キーボードの健全率、破損キーがない状態を加味して加点します。ローマ字数が多い読みほど文字数ボーナスが増えます。`shi` / `si` のような入力方式の違いでは得点差が生じません。誤答では少量減点されます。

20語モードでは、20語完走時にクリアタイムボーナスとノークラッシュボーナスが加算されます。

世界ランキングはありません。各モード・各難易度ごとに上位5件を端末内へ保存します。ランキング画面はPNG画像として共有できます。

## 語彙データを編集する

編集元は `data/words.csv` です。

| 列 | 内容 |
|---|---|
| `level` | `beginner` / `intermediate` / `advanced` / `expert` / `oni` |
| `level_ja` | 表示確認用の日本語難易度 |
| `word` | 画面に表示する語 |
| `readings` | ひらがな。複数読みは `/` 区切り |
| `rank` | 難易度内の1〜5 |

編集後に以下を実行します。

```bash
python tools/validate_words.py
python tools/build_words.py
```

Python標準ライブラリのみを使用します。

## 難易度と漢検について

難易度は、日本漢字能力検定の対象漢字範囲と一般的な学校学習段階を参考にした、本ゲーム独自の目安です。

- 漢検の公式問題、過去問題、公式教材の問題文は収録していません。
- 漢検協会による監修、認定、推奨を受けた作品ではありません。
- 「この語が必ず該当級で出題される」という保証はありません。
- 読みの誤りや難易度調整はIssueまたはPull Requestで修正できます。

詳細は `DATA_POLICY.md` を参照してください。

## 広告を設置する場合

ゲーム本体は外部通信を行いません。広告タグを追加した場合は、その広告事業者への通信が新たに発生します。広告事業者の規約に従い、プライバシーポリシー、Cookie・広告識別子の表示、年齢層への配慮を別途実施してください。

誤操作を避けるため、プレイ中の単語カード、入力欄、キーボードの周辺には広告を置かないことを推奨します。タイトル画面下部またはリザルト画面下部が比較的安全です。
